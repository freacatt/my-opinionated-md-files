# my-opinionated-md-files

Curated, opinionated markdown files by [freacat](https://github.com/freacat). Drop-in prompts and rules for steering AI assistants.

## Files

| File | Purpose |
| --- | --- |
| [`absolute_mode.md`](absolute_mode.md) | Strips filler, emojis, and engagement bait. Blunt, direct replies only. |
| [`humanize-writing.md`](humanize-writing.md) | Rules that make output read like a person wrote it, not a language model. |
| [`i-have-adhd.md`](i-have-adhd.md) | Concise, action-first replies shaped for a reader with ADHD. |
| [`initiate-development.md`](initiate-development.md) | Setup rules to run before writing feature code in any project. |

## Usage

Paste a file into a chat, or reference it from your `CLAUDE.md` or system prompt. Some files stay active until you say "stop" (e.g. `stop adhd mode`).

## Note

These are personal preferences, not universal best practice. Fork and edit to taste.
