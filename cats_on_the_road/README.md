## فرمولِ پرامپتِ خوب (از اولِ ویدیو)

یه پرامپتِ خوب معمولاً پنج تیکه داره. لازم نیست هر بار همه‌ش باشه؛ هر کدوم رو اضافه کنی، جواب یه پله بهتر می‌شه.

1. **نقش** — بهش بگو کیه.
2. **زمینه** — بگو تو کی هستی و قضیه چیه.
3. **کار** — دقیقاً چی می‌خوای.
4. **قالب** — جواب چه شکلی باشه.
5. **محدودیت** — چی نباشه.

**مثالِ ویدیو (سفارشِ لوگو):**

```text
یه شیرینی‌پزیِ خونگی دارم که تو اینستاگرام می‌فروشه، مشتری‌هام بیشتر جوونن. می‌خوام سفارشِ لوگو بدم به یه طراحِ فریلنسر. یه بریفِ کوتاه براش بنویس: حسِ گرم و بامزه، رنگ‌های صورتی و کرم، تحویل دو هفته‌ای. به شکلِ لیست، و بنویس چی نمی‌خوام: کیک و کلاهِ آشپزیِ کلیشه‌ای.
```

## انواعِ پرامپت (از اولِ ویدیو)

| نوع | یعنی | مثالِ ویدیو |
|---|---|---|
| زیرو-شات (zero-shot) | بدونِ مثال | «برای کیکِ شکلاتیم یه توضیح بنویس که بذارم تو پیجم.» |
| وان-شات (one-shot) | یه مثال | «توضیحِ کیکِ شکلاتیم اینه: هفتاد درصد کاکائو، کم‌شیرین، برای شش نفر. برای کیکِ لیمویی هم همین‌جوری بنویس.» |
| فیو-شات (few-shot) | چند مثال | → [دقیقاً مثلِ این](18-exactly-like-this.md) |

| زنجیره‌ی فکر (chain-of-thought) | قدم‌به‌قدم فکر کنه | «قدم‌به‌قدم فکر کن، بعد جواب بده.» → [اول نقشه](16-plan-first.md) |
