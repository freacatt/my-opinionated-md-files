# ۲۰ · پرامپتمو بهتر کن (Improve my prompt)

> از ویدیوی «۲۰ پرامپت» — Cats on the Road · پلی‌لیستِ AI for Everyone · [همه‌ی پرامپت‌ها](README.md)

**کِی به کار میاد:** همیشه، وقتی حوصله‌ی نوشتنِ پرامپتِ کامل رو نداری.

## پرامپت (فارسی)

```text
می‌خوام [کاری که لازم داری]. قبل از جواب، این درخواست رو به یه پرامپتِ کامل تبدیل کن، بعد با همون جواب بده.
```

## Prompt (English)

```text
I want to [what you need]. Before answering, turn this request into a complete prompt, then answer using it.
```

**مثالِ ویدیو:** می‌خوام یه ایمیل به استادم بنویسم برای تمدیدِ مهلتِ پروژه.

`[ ]` = جاهایی که باید با چیزِ خودت پر کنی.
